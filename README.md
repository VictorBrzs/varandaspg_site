# Varandas Restaurante Website

Site profissional para o Varandas Restaurante em Praia Grande.

## 📋 Sobre o Projeto

Website responsivo apresentando:
- Múltiplas variações de design
- Galeria de pratos e ambiente
- Design moderno e sofisticado
- Tema litorâneo com paleta de cores inspirada no oceano

## 🎨 Variações de Design

- `varandas_restaurante_oficial/` - Design oficial
- `varandas_in_cio_1/` - Variação 1
- `varandas_in_cio_2/` - Variação 2
- `varandas_in_cio_3/` - Variação 3

## 📁 Estrutura do Projeto

```
├── varandas_restaurante_oficial/   # Site principal
├── varandas_in_cio_1/              # Variações alternativas
├── varandas_in_cio_2/
├── varandas_in_cio_3/
├── coastal_heritage/               # Design system
├── assets/                         # Imagens e recursos
└── README.md
```

## 🚀 Como Usar

### Desenvolvimento Local

Simplesmente abra qualquer arquivo `code.html` em um navegador.

### Deploy no Vercel

1. Push para GitHub
2. Conecte seu repositório no Vercel
3. Vercel detectará automaticamente e fará o deploy

## 📝 Arquivos Principais

- **code.html** - Arquivo HTML de cada variação
- **DESIGN.md** - Sistema de design e paleta de cores

## 🌐 Deployment

Este projeto pode ser facilmente deployado em:
- **Vercel** (recomendado)
- GitHub Pages
- Netlify
- Qualquer servidor web estático
